# 🌐 텔레그램 다국어 실시간 자동 통번역 봇 (한국어 ↔ 영어 ↔ 베트남어 ↔ 중국어 ↔ 스페인어)

텔레그램 그룹 대화방 및 1:1 대화에서 **한국어, 영어, 베트남어, 중국어, 스페인어**를 자동으로 감지하여 실시간으로 인용 답장 번역을 제공하는 고성능 통번역 봇입니다.

---

## ✨ 핵심 기능 요약

1. **대화방 초대 시 즉시 대화형 언어 질문 온보딩**
   - 봇이 대화방에 새로 초대되면, 채팅방에 **"어떤 언어를 번역하시겠습니까?"** 인라인 버튼 카드를 즉시 전송합니다.
   - 방장이나 관리자가 원하는 언어를 클릭 한 번으로 선택하면 즉시 번역이 개시되며, 안내 카드는 자동으로 삭제되어 대화방을 쾌적하게 유지합니다.
   - 기존에 이미 설정되어 사용 중이던 방의 설정은 패치나 재배포 후에도 100% 안전하게 보존됩니다.

2. **5개국어 상호 자동 통번역 & 다중 체크박스(중복 선택) 지원**
   - 🌐 **5개국어 전체 모드 (`all`)**: 한국어 ➡️ 🇺🇸 영어 + 🇻🇳 베트남어 + 🇨🇳 중국어 + 🇪🇸 스페인어 4개국어 동시 번역!
   - ☑️ **원하는 언어 다중 선택 (체크박스)**:
     - 대화방에서 `/lang` 입력 시 실시간 체크박스 카드가 열려 **원하는 언어를 자유롭게 복수 선택** 가능 (예: 영어+베트남어만, 영어+중국어만, 3개국어만 등)
     - 버튼 클릭으로 즉시 체크(`☑️`) / 해제(`⬜`) 후 `[✅ 설정 완료]` 버튼을 누르면 적용 완료
     - 명령어로도 직접 즉시 설정 가능: `/lang all`, `/lang en vi`, `/lang en zh`, `/lang vi es` 등
   - 🇺🇸 **한-영 모드 (`ko-en`)**: 한국어 ↔ 영어 전용 번역
   - 🇻🇳 **한-베 모드 (`ko-vi`)**: 한국어 ↔ 베트남어 전용 번역
   - 🇨🇳 **한-중 모드 (`ko-zh`)**: 한국어 ↔ 중국어(간체) 전용 번역
   - 🇪🇸 **한-스 모드 (`ko-es`)**: 한국어 ↔ 스페인어 전용 번역

3. **행정용어집(`언어권별_행정용어.xlsx`) 지능형 자동 치환**
   - 사내 및 조직 고유 행정용어를 4개 외국어로 정확하게 표준 치환
   - 한국어 조사 분리(-님이, -에서, -에게 등) 및 최장 일치(Greedy Match) 알고리즘 적용

4. **대화방 전용 경량화 `/help` 지원**
   - 대화방에서 `/help` 입력 시 총괄 관리자 명령 등 불필요한 내부 시스템 명령은 숨기고, 대화방 실무 필수 명령어만 깔끔하게 노출합니다.

5. **포럼 주제(Topic) 선택적 번역 지원**
   - 주제별로 나뉜 포럼 그룹방에서 특정 주제(토픽)만 골라서 번역 활성화 가능 (`/topic on`)
   - 다른 잡담이나 공지 주제는 조용히 유지하고, 실제 다국어 소통이 필요한 주제만 깔끔하게 번역

6. **중앙 총괄 관리자 & 현장 관리자 2단계 권한 체계 (2-Tier RBAC)**
   - **총괄 관리자**: 대화방에 직접 들어가지 않고도 1:1 DM에서 모든 연결 대화방 목록 조회(`/groups`), 원격 승인 및 차단/퇴장 통제 가능
   - **현장 그룹 관리자**: 텔레그램 그룹의 방장(Owner) 및 관리자(Admin)는 자기 방에서 토픽 켜기/끄기(`/topic`), 언어 설정(`/lang`), 번역 제어(`/translate`) 자유롭게 가능

7. **스마트 필터링 & 무중단 안정성**
   - 단순 리액션/감탄사/단답형 자동 필터링 ("아멘", "Amen", "dạ", "vâng", "ok", "好的", "gracias" 등)
   - 메시지 삭제 시 에러 방지 (`safe_reply` 자동 폴백)
   - Render 무중단 재배포 시 409 Conflict 자동 완화

8. **철저한 보안 지침 (S1~S13) 완벽 준수**
   - 추측 불가능한 비밀 Deep Link 게이트 (`/start <payload>`) 통과자만 접근 가능
   - 미승인 대화방에 초대될 경우 완벽한 침묵(무반응) 유지
   - SQLite 원자적 쓰기 DB 및 메모리 레이트 리밋 / 무차별 대입 차단
   - 코드 및 로그 내 개인정보 / 토큰 완전 마스킹

## 📁 디렉터리 구성

- `bot.py` : 텔레그램 봇 메인 로직 (이벤트 수신, 포럼 스레드 제어, 2단계 권한 판정, 웹 헬스체크)
- `db.py` : SQLite 기반 원자적 저장소 (`users`, `groups`, `group_topics`)
- `translator.py` : 5대 언어 감지, 스마트 필터링, Google GTX POST 엔진 & DeepL 하이브리드 연동
- `security.py` : S4/S5/S10 보안 모듈 (HMAC 타이밍 세이프 검증, 레이트 리밋, 권한 체커)
- `test_translator.py` : 언어 감지 및 필터 규칙 유닛 테스트
- `render.yaml` / `DEPLOY_RENDER.md` : Render 클라우드 배포 설정 및 24시간 유지 가이드

## 🛠️ 명령어 일람표

### 👑 1. 총괄 관리자 전용 (봇과의 1:1 개인 대화)
| 명령어 | 설명 |
| :--- | :--- |
| `/groups` | 봇이 연결된 모든 그룹방 목록, 승인 상태, 언어 모드 조회 및 원격 제어 |
| `/set_lang [그룹ID] [모드]` | 특정 대화방 언어 모드 원격 지정 (`all`, `ko-en`, `ko-vi`, `ko-zh`, `ko-es`) |
| `/approve_group [그룹ID]` | 특정 대화방을 원격으로 사용 승인 |
| `/ban_group [그룹ID]` | 특정 대화방을 원격 차단 및 봇 즉시 퇴장 처리 |
| `/grant_admin [유저ID]` | 보조 총괄 관리자 권한 부여 |
| `/revoke_admin [유저ID]` | 관리자 권한 회수 (Lockout 방지 적용) |

### 🛡️ 2. 현장 대화방 관리자 / 공통 명령어 (그룹 대화방)
| 명령어 | 설명 |
| :--- | :--- |
| `/lang` | **언어 선택 카드 열기** (버튼 클릭으로 언어 즉시 변경) |
| `/lang [모드]` | 명령어로 직접 언어 변경 (`ko-en`, `ko-vi`, `ko-zh`, `ko-es`, `all`) |
| `/translate on/off` | 그룹 전체 번역 기능 켜기 / 일시 정지 |
| `/topic on` | **현재 주제(Topic)에서만** 번역 켜기 (다른 토픽 조용) |
| `/topic off` | 현재 주제(Topic)에서 번역 끄기 |
| `/topic all` | 해당 그룹의 모든 주제에서 번역 켜기 |
| `/status` | 현재 방의 승인 상태, 언어 모드, 토픽 번역 여부, 엔진 상태 확인 |
| `/help` | 대화방 전용 사용 안내 및 주요 명령어 확인 |
| `/myid` | 본인의 텔레그램 숫자 ID 확인 |
