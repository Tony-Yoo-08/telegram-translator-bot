# 🌐 해외선교 총괄 관제 포털 (Executive Mission Control System)

본 시스템은 **중앙 부장, 총무, 서무 3인 전용**으로 제작된 최고 수준의 보안성과 직관성을 갖춘 폐쇄형 실시간 해외선교 통합 관제 시스템입니다.

---

## 💎 주요 특징 및 기능 명세

### 1. ☀️ 다크 모드 & 🌙 라이트 모드 듀얼 테마 지원
* 상단 헤더의 **[☀️ 라이트 모드] / [🌙 다크 모드]** 버튼을 통해 원클릭으로 테마를 전환할 수 있습니다.
* 다크 모드에서는 깊이감 있는 옵시디언 다크 테마와 보석 글래스모피즘이 적용되며, 라이트 모드에서는 공공/금융권 수준의 깔끔하고 정돈된 화이트 인트라넷 테마가 적용됩니다.
* 지도 타일 역시 테마에 맞추어 **Esri Light Canvas(밝은 테마) ↔ Esri Dark Canvas(다크 테마)**로 실시간 자동 동기화되며, 글로벌 도로망(Street), 위성 항공 지도(Satellite), OSM, CARTO(API 키 연동) 등 다양한 고화질 베이스맵을 원클릭으로 선택할 수 있습니다.

### 2. 🗺️ 12지파 해외지경판 (12지파 지경 개수 상세 KPI & 자동 지오코딩)
* **도시명 입력 시 위도·경도 자동 매핑 (Geocoding Auto-Engine)**:
  * 위도/경도를 수동으로 검색하거나 입력할 필요 없이 **도시명(예: 베를린, 파리, 뉴욕, 프랑크푸르트 등)만 입력하면 즉시 전 세계 표준 좌표가 자동 산출 및 적용**됩니다.
  * **전 세계 150개 이상 핵심 도시 오프라인 사전**이 내장되어 인터넷이 없는 환경에서도 0초 즉각 매핑되며, 미등록 소도시의 경우 오픈스트리트맵(Nominatim) 온라인 정밀 검색을 통해 자동으로 좌표를 찾아 입력해 줍니다.
* **타지파 성도수 미상 시 '교회 / 지역 / 개척지' 직접 등급 등록 지원**:
  * 타지파의 경우 정확한 성도 수를 알지 못하더라도 **지경 등급(⛪ 교회 / 🚩 지역 / 🧭 개척지)**만 선택하면 성도 수 입력을 생략(공란)하고도 즉시 정상 등록됩니다.
  * 선택된 등급에 맞추어 상단 종합 KPI 및 12지파별 지경 보유 현황(교회/지역/개척지 개수)에 실시간으로 완벽하게 합산 집계됩니다.
* **워터마크 0% 클린 맵 엔진**: 최근 CARTO 비인증 타일 정책 변경으로 발생했던 "API KEY REQUIRED" 워터마크 문제를 완전히 해결하여, 별도의 API 키 없이도 100% 무료 및 워터마크 0%로 전 세계 국경선과 도시명이 선명하게 표출됩니다. (CARTO 공식 무료 API 키 연동도 동시 지원)
* **12지파 공식 색상표(PANTONE Solid Coated) 100% 반영**:
  * 1. 요한 (`#009651` 녹보석) / 2. 베드로 (`#00a0e9` 벽옥) / 3. 부산야고보 (`#1d2088` 남보석)
  * 4. 안드레 (`#59c3e1` 옥수) / 5. 다대오 (`#eb6120` 홍마노) / 6. 빌립 (`#d7005b` 홍보석)
  * 7. 시몬 (`#fdd000` 황옥) / 8. 바돌로매 (`#86cab6` 녹옥) / 9. 마태 (`#e39300` 담황옥)
  * 10. 맛디아 (`#6FBA2C` 비취옥) / 11. 서울야고보 (`#005dac` 청옥) / 12. 도마 (`#7f1084` 자정)
* **12지파별 지경 보유 개수 상세 표기 KPI**:
  * 상단 종합 지표: 전 세계 총 지경 수 및 등급별 요약(교회/지역/개척지).
  * 12지파별 개별 지경 현황 카드: 요한부터 도마까지 **각 지파가 보유한 지경 수(개)와 교회·지역·개척지 세부 구성**을 한눈에 표시.
  * 카드를 클릭하면 해당 지파만 지도에 즉각 필터링되는 스마트 연동 제공.
* **3단계 등급 체계**:
  * 🧭 **개척지 (Pioneer)**: 성도 0명 ~ 49명 (신규 확장 대상 도시) - 청록색 뱃지
  * 🚩 **지역 (Branch)**: 성도 50명 ~ 299명 (준교회 형태 거점) - 호박색 뱃지
  * ⛪ **교회 (Church)**: 성도 300명 이상 (정식 자립 교회) - 에메랄드 뱃지 & 실시간 펄스 애니메이션
* **도시별 지파 고유 색상 라인 & 영역 정밀 채색 엔진 (City Boundary & Shading)**:
  * 각 도시 거점마다 **해당 지파의 고유 공식 색상 라인(점선 스트로크)과 반투명 은은한 채색(Fill) 폴리곤**이 지도 상에 펼쳐져 각 지파의 관할 지경을 한눈에 시각적으로 파악할 수 있습니다.
  * **[🎨 지경 채색 ON/OFF] 스마트 토글 버튼**: 지도 서브 필터 바에서 원클릭으로 도시 영역 채색을 켜거나 끌 수 있으며, 설정 상태는 `localStorage`에 자동 영구 보존됩니다.
  * **듀얼 레이어 하이브리드 지경 엔진**: 오프라인(`file://`) 환경에서도 0초 지연 없이 도시 규모 및 등급(교회/지역/개척지)에 맞춘 자연스러운 지형 경계 폴리곤이 즉각 렌더링되며, 온라인 환경에서는 오픈스트리트맵(OSM) 정밀 행정구역 경계를 비동기 수신하여 캐시 및 업그레이드합니다.
  * **인터랙티브 반응형 마이크로 이펙트**: 마우스 호버 시 경계선이 화이트 네온(`weight: 3.8`)으로 강조되고 내부 채색이 선명해지며, 툴팁에 `[지파명] 도시명 관할 지경`이 표출됩니다. 채색 영역을 클릭하면 해당 도시 거점 상세 드로어가 즉시 열리며 지도가 부드럽게 줌인(FlyTo)됩니다.
  * **지파별 선교 네트워크 연결 라인**: 특정 지파를 선택·필터링할 경우, 해당 지파가 개척한 도시 거점 간을 잇는 고유 색상의 대시 라인(Mission Route)이 자동으로 표시됩니다.
* **도시 단위 상세 세분화 & 인터랙션**: 지파별 필터, 등급별 필터, 도시/국가/사역자 실시간 검색, 우측 슬라이드 상세 현황판, 신규 도시 지경 등록 모달.

### 3. 👥 바돌로매지파 해외 인재 현황판 (독립 분리 보드)
* **완전 분리된 독립 현황판**: 상단 탭 전환 시 인재 전용 KPI 스트립과 카드 갤러리가 활성화되며, 지도와 간섭 없이 독립적으로 운영됩니다.
* **카드 갤러리 그리드 레이아웃**: 인재의 사진, 성명, 소속 부서, 직분, 파견 상태를 직관적으로 파악.
* **다국어 구사 역량 및 공인 시험 표기**: 독일어, 영어, 스페인어, 프랑스어 등 언어별 숙련도(`C1`, `B2` 등) 및 자격증 뱃지.
* **실시간 파견 상태 표시**:
  * 🟢 즉시 파견 가능 / 🔵 현지 파견중 / 🟡 사역 연수중 / ⚪ 국내 사역 (언어 지원)
* **스마트 필터링**: 언어별 원클릭 필터, 파견 상태별 필터, 키워드 검색.
* **심층 역량 모달**: 클릭 시 공인 어학 성적, 체류 경험, 특기, 임원진 추천 메모 확인.
* **신규 인재 등록**: 새로운 언어 가능 인재 실시간 접수 및 등록.
* **인재 정보 수정 & 삭제**: 카드 및 상세 프로필 모달에서 `[✏️ 수정]` 버튼을 통해 성명, 직분, 언어 등급, 파견 상태 등을 즉시 수정하고 `[🗑️ 삭제]` 가능.

### 4. 🛡️ 총괄·개발자 관제 현황판 (Admin & Audit System)
* **상단 독립 관제 탭 제공**: `[🛡️ 총괄·개발자 관제]` 탭을 통해 중앙 임원진 및 개발자 전용 시스템 통제 환경 제공.
* **중앙 승인 계정 관리**:
  * 승인 계정 목록 조회 (아이디, 담당자 성명/직분, 권한 역할 등급, 발급일, 최근 로그인 일시).
  * 신규 관리자 계정 즉시 발급 (권한 등급: MASTER, EXECUTIVE, STAFF, DEV).
  * 관리자 계정 정보 수정 (`[✏️ 수정]` 버튼을 통해 담당자 직분 및 권한 등급 실시간 변경).
  * 계정 비밀번호 실시간 변경 모달.
  * 계정 안전 삭제 (마스터 계정 및 본인 계정 삭제 방지 보호 장치 내장).
* **실시간 시스템 사용 이력 및 감사 로그 (Audit Logs)**:
  * 로그인/로그아웃, 지경 추가/수정/개별삭제/일괄삭제, 인재 등록/수정/삭제, 계정 발급/수정 등 모든 시스템 작업 자동 영구 기록.
  * 유형별 필터 칩(전체, 보안인증, 지경제어, 인재관리, 계정제어) 및 실시간 검색 지원.
  * 감사 로그 **CSV 파일 원클릭 다운로드(Excel 호환 UTF-8 BOM)** 지원.
  * 필요 시 감사 로그 전체 비우기(초기화) 기능 제공.
* **12지파 지경 데이터 일괄 제어**:
  * **가데이터 일괄 삭제**: 현재 등록된 28개 가데이터를 1클릭으로 전체 비워 실제 사역 데이터 입력 준비.
  * **샘플 데이터 복원**: 테스트 또는 시연이 필요할 때 12지파 28개 표준 샘플 데이터 즉시 원상 복구.
  * **지경 JSON 백업 다운로드**: 전체 지경 데이터를 표준 JSON 파일로 안전하게 백업 및 보관.

### 5. 🗺️ 해외지경판 데이터 제어 (도시명 자동 좌표 매핑, 등급 지정 등록, 수정 및 삭제)
* **도시명 입력 시 좌표 자동 산출**: 지경 등록/수정 모달에서 도시명 입력 시 위도·경도가 즉시 자동 계산되어 입력되며, 좌표를 직접 몰라도 간편하게 등록할 수 있습니다.
* **타지파 등급 지정 등록**: 성도 수를 파악하기 어려운 타지파의 경우 '교회 / 지역 / 개척지' 등급만 선택하면 성도 수(인원) 입력 없이도 거점으로 바로 등록되어 지경 현황에 정확히 반영됩니다.
* **지경 영역 채색 및 경계선 토글**: 지도 상단 `[🎨 지경 채색 ON/OFF]` 버튼을 통해 도시별 지파 색상 라인 및 채색 영역을 언제든지 켜고 끌 수 있습니다.
* **지경 정보 실시간 수정**: 지도 거점 클릭 후 우측 사이드 드로어의 `[✏️ 이 지경 정보 수정]` 버튼으로 소속 지파, 도시명, 지경 등급, 성도 수, 책임 사역자, 좌표, 개척 연도, 비고 등을 모달에서 손쉽게 수정 및 즉각 반영.
* **개별 거점 삭제**: 우측 사이드 드로어 하단의 `[🗑️ 이 지경 거점 삭제]` 버튼으로 불필요한 거점 즉시 삭제.
* **가데이터 일괄 삭제**: 지도 상단 컨트롤 바의 `[🗑️ 가데이터 일괄 삭제]` 버튼을 통해 초기 28개 지경을 즉시 초기화.
* **로컬 스토리지 영구 보존**: 새로고침이나 브라우저 재실행 후에도 수정/삭제된 상태 및 신규 등록된 데이터가 안전하게 유지됩니다.

### 6. 🔒 원클릭 실행 및 보안 원천 차단
* **Zero-CORS 단독 실행 지원 (`app.bundle.js`)**: 로컬 파일(`file://`)로 더블클릭하여 열어도 모든 자바스크립트 및 지도 엔진이 100% 즉시 구동됩니다.
* **검색엔진 차단**: `noindex, nofollow, noarchive, nosnippet` 메타 태그 적용으로 구글/네이버 등 검색엔진 노출 100% 원천 차단.
* **보안 접속 게이트웨이**: 사전 부여된 ID/PW 입력 필수 (세션 기반 유지, 간편 접속 지원).
* **비용 0원 영구 운영**: 외부 유료 API나 구독료 없이 무료 클라우드 환경에서 영구 동작.

## ☁️ GitHub 저장소 연동 및 Vercel 1분 무료 배포 가이드

스마트폰, 태블릿, 외부 어디서든 24시간 실시간으로 접속하기 위해 GitHub Private 저장소와 무료 클라우드(Vercel)에 배포하는 순서입니다.

### 1단계: GitHub 비공개(Private) 저장소 생성
1. [GitHub](https://github.com)에 로그인 후 우측 상단 `+` ➡️ `New repository` 클릭
2. Repository name에 `overseas-mission-system` 입력
3. **반드시 Private(비공개)를 선택** (외부인 열람 불가)
4. `Create repository` 클릭

### 2단계: 코드 업로드 (터미널)
프로젝트 폴더에서 실행:
```bash
git init
git add .
git commit -m "feat: overseas mission control portal with dual themes, 12 tribes kpi and talents gallery"
git branch -M main
git remote add origin https://github.com/[깃허브_아이디]/overseas-mission-system.git
git push -u origin main
```

### 3단계: Vercel 1클릭 무료 배포 (영구 무료)
1. [Vercel](https://vercel.com)에 GitHub 계정으로 가입/로그인
2. `Add New...` ➡️ `Project` 클릭
3. 방금 올린 `overseas-mission-system` 비공개 저장소 옆의 `Import` 버튼 클릭
4. 설정 변경 없이 `Deploy` 버튼 클릭
5. **완료!** 생성된 고유 보안 웹 주소(예: `https://overseas-mission-xxx.vercel.app`)로 어디서든 실시간 접속 가능합니다.
